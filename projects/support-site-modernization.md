# AI-Assisted Support Site Modernization

## Context

A support site is often the first place customers go when they get stuck, and it is increasingly the place AI tools go to find answers on a customer's behalf. Content that was written over many years, by many authors, tends to drift: terminology varies, formatting is inconsistent, metadata is thin, and pages are hard for both search engines and AI assistants to interpret.

IMPLAN's Support Site modernization addresses both audiences: people looking for help, and AI systems retrieving product knowledge.

---

## My role and scope

- **Built:** the AI-assisted workflow, using Claude Code, that supports the content modernization.
- **Applied:** analytics and Marketing input to decide where and how content changes are made.
- **Worked within:** a cross-functional governance process with input and approval from leadership, Product, and Marketing.

This is an AI-assisted workflow with human review at each stage. It is not an autonomous system: people decide what changes, and people approve what ships.

---

## What I did

### Built an AI-assisted content workflow with Claude Code

Used Claude Code to work through existing Support Site content systematically, applying consistent standards across articles:

- Terminology updated to match current product language
- Formatting standardized across articles
- Metadata improved for discoverability and context
- Content structured for search (SEO) and for AI answer engines (AEO)

### Used analytics to set priorities

Used Google Analytics data to understand how customers use the site and to inform where content changes should be prioritized.

### Incorporated Marketing input on calls to action

Worked with Marketing input to guide call-to-action placement, so support content connects customers to relevant next steps without getting in the way of the answer they came for.

### Prepared content for AI-ready knowledge access

Improved MCP readiness so Support Site content is better structured for AI tools and assistants that retrieve product knowledge. This connects to my [evaluation of IMPLAN's MCP server](api-developer-education.md#mcp-server-evaluation) and the broader goal of making product knowledge accessible wherever customers are working.

---

## Process and governance

AI speeds up the work; it does not replace judgment. The workflow is built around controls:

- **Human review:** AI-assisted changes are reviewed before they are accepted.
- **Security checks:** security review is part of the process, not an afterthought.
- **Consistent standards:** terminology, formatting, and metadata rules are defined up front so changes are predictable and reviewable.
- **Cross-functional launch governance:** leadership, Product, and Marketing provide input and approval, so the modernized site reflects product accuracy, brand and messaging needs, and company priorities.

---

## Outcomes

- A repeatable, reviewable workflow for modernizing support content at scale
- More consistent terminology, formatting, and metadata across the site
- Content better structured for search engines and AI answer engines
- Stronger foundation for AI-ready knowledge access, including MCP
- Clearer governance and alignment across leadership, Product, and Marketing
