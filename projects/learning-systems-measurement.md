# Learning Systems, Documentation, and Measurement

## Overview

Customer-facing content only scales when it sits on a solid system: organized content, clear pathways, reporting, governance, and feedback loops that show whether resources are helping users succeed.

My work has included documentation modernization, LMS migration, and support-deflection resources that make customer-facing content easier to maintain and evaluate.

Measurement for this work, including the Education Services metrics dashboard, is covered in [Customer and Program Analytics](customer-program-analytics.md).

---

## LMS Migration and Learning Infrastructure

I am currently leading work to migrate online learning content into an LMS. This work is not only a platform move; it requires decisions about course structure, content organization, learner pathways, reporting, ownership, and long-term maintenance.

Key workstreams include:

- Content inventory and audit
- Course and module structure
- Learning path planning
- Metadata and tagging strategy
- Reporting needs
- Governance and update processes
- Alignment with customer and internal education goals

---

## GAUSS Documentation Modernization

At Aptech, I managed a major documentation modernization effort for GAUSS, moving static PDF-style documentation into a searchable, online-first documentation hub. The documentation system emphasized practical examples, clearer organization, and better self-service for users.

This work reduced support burden, improved user experience, and created a stronger foundation for ongoing education, product releases, and technical support.
