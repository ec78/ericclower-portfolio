# API and Developer Education for Technical Products

## Overview

A recurring theme in my work is helping technical users understand how to apply complex software capabilities in real workflows. This includes API demos, code examples, documentation, technical tutorials, and product education that connect what a platform can do with how users can actually use it.

My experience spans both customer-facing developer education and product-side API design. At IMPLAN, I have expanded API learning content and become a primary internal resource for API demos related to developer access. At Aptech, I helped design and document streamlined APIs for GAUSS modeling tools and created examples that helped users apply advanced analytical functionality with less friction.

---

## How I Approach Developer Education

- Start with the workflow the user is trying to complete.
- Explain the concepts and constraints behind the tool, not just the syntax.
- Use examples that are close enough to real work to build confidence.
- Provide multiple entry points: quickstart, conceptual explanation, reference documentation, demo, and deeper tutorial.
- Connect technical education to product outcomes, adoption, and customer success.
