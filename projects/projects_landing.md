## Earlier Quantitative Analysis

These projects show the analytical foundation behind my product and technical work.

- **[Trilemma Index Computation](https://users.ssc.wisc.edu/~mchinn/ACI_Trilemma_s_Oct09.pdf)**  
  Supported academic research by cleaning and integrating international macroeconomic and financial datasets and computing multiple dimensions of the trilemma index using consistent time-series techniques.

- **[Inflation Forecasting with Commodity Price Aggregates](https://www.sciencedirect.com/science/article/abs/pii/S0304407614001547)**  
  Contributed data processing, cointegration testing, and VAR/VECM estimation to a cross-country inflation forecasting study evaluating the predictive value of global commodity price aggregates.

- **Price Discovery Code Consultant**  
  Contracted to extend and adapt an existing estimation codebase, delivering enhanced coefficient estimates, bootstrapped inference, and publication-ready outputs aligned with academic standards.

- **Time Series Forecasting for Private Client**  
  Conducted end-to-end time-series analysis, including data preparation, diagnostics, model estimation, and forecast evaluation, delivering both code and interpretive guidance.

- **Review of Inflation Forecasting Methodology**  
  Evaluated an ARIMA-based forecasting process and developed a modular evaluation pipeline to improve transparency, reproducibility, and interpretability.
