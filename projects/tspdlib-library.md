# TSPDLIB: Open-Source Ecosystem Strategy

## Context

[TSPDLIB](https://docs.aptech.com/gauss/tspdlib/docs/tspdlib-landing.html) is an open-source GAUSS library for unit root, stationarity, cointegration, and related econometric tests. It began as a collection of procedures compiled by a GAUSS user and researcher.

Aptech had not previously taken an active role in a user's open-source library. I made the case that it should, and TSPDLIB became the first user-developed open-source library that Aptech actively promoted, supported, and helped develop.

**The arc:** market insight → business hypothesis → partnership → product development → GTM → ecosystem adoption.

---

## My role and scope

- **Championed** the strategy: made the case for Aptech to actively support and help develop the library.
- **Partnered directly** with the contributing user on product development.
- **Contributed directly** to the product development, documentation, and GTM work described below.
- The original library was compiled by the contributing user.

---

## The Strategic Case

### Hypothesis

A valuable, free econometrics library could:

- **Reach:** expand GAUSS's reach to new researchers and econometric users.
- **Entry point:** give those users a reason to start working in the broader GAUSS ecosystem.
- **Product strengths:** showcase areas where GAUSS had real advantages, especially computational speed and transparency.
- **Competitive gap:** address an area where competing tools had relatively limited offerings.
- **Credibility:** draw on the contributing user's research network and standing in the econometrics community.

### Evidence behind the decision

- Persona interviews
- Observed GAUSS product strengths
- Competitive gaps in unit root, stationarity, and cointegration tooling
- The contributor's research network and presence in the econometrics community

---

## Product Development

Turning a user-compiled library into a product-quality resource meant bringing it in line with the rest of GAUSS:

- **API standardization:** updated the library's interface to match GAUSS API conventions, so it felt like part of the platform.
- **Platform integration:** updated the code to use built-in GAUSS functionality.
- **Output and UX:** improved how results are presented, including more directly interpretable result statements that tell users what a test result means.
- **Documentation:** built a complete technical documentation suite.
- **Installation:** supported direct installation through the GAUSS Package Manager.

## Partnership Strategy Beyond TSPDLIB

TSPDLIB tested a broader idea: that partnerships with technical users and researchers could extend the GAUSS ecosystem. I participated in decisions about:

- Whether user-developed libraries were strategically valuable
- Whether Aptech should actively support them, and how deeply to participate in development
- How they should be distributed
- How they should be positioned to the market
- How they could broaden GAUSS adoption

This connected to the public open-source catalog established through the [GAUSS GitHub organization](github-transition.md).

---

## Outcomes

- **Research visibility:** Google Scholar lists 70+ academic papers citing the library.
- **Public visibility:** TSPDLIB is the most prominent repository among Aptech's popular public [GitHub repositories](https://github.com/aptech/tspdlib), and one of Aptech's most visible public technical resources.
- **Community:** the library became a centerpiece of the contributing user's annual international applied GAUSS workshop.
- **Precedent:** the first user-developed library that Aptech actively promoted, supported, and helped develop.
