# Learning Systems, Metrics, and LMS Migration

I build learning systems that can scale across audiences, channels, and product changes. This includes education metrics, content structure, LMS planning, documentation systems, support resources, and feedback loops that help teams evaluate what is working.

---

## Representative work

At IMPLAN, I created an education team metrics and KPI dashboard to communicate the value of learning programs and evaluate program success. I am also leading the migration of online learning content into an LMS, including content organization, learning path planning, reporting needs, and long-term maintenance considerations.

At Aptech Systems, I managed GAUSS's online documentation hub, moving static resources into a searchable, example-driven system that improved self-service and reduced support friction.

---

## What this work included

- Defining education team KPIs and program success measures
- Building reporting that helps evaluate learner engagement and program effectiveness
- Organizing learning content for LMS migration and future maintenance
- Planning course structures, learning paths, tagging, and reporting needs
- Auditing existing content and identifying gaps, duplication, or outdated resources
- Creating documentation and support resources that improve user self-service
- Using metrics and support patterns to guide education roadmap decisions

---

## Why it matters

Learning programs need more than content. They need structure, governance, measurement, and maintenance so users can find the right resources and teams can understand whether education is improving adoption, confidence, and support outcomes.
