# AI Learning and Workflow Enablement

I use AI as both a work tool and a learning subject: a way to improve education workflows, accelerate content development, and help employees build practical confidence with new tools.

---

## Representative work

At IMPLAN, I designed an internal AI in the Workplace learning program to help employees apply AI tools to everyday work. The program focuses on practical examples, responsible use, and workflow-focused training rather than abstract AI concepts alone.

At Aptech Systems, I applied AI tools to documentation drafting, content planning, code example generation, Markdown and HTML formatting, and support workflow improvement. These experiments helped reduce manual production work and make educational content more consistent.

---

## What this work included

- Designing internal learning resources for practical AI adoption
- Developing responsible-use guidance for everyday workplace scenarios
- Creating examples that show how AI can support writing, analysis, support, documentation, and workflow planning
- Using AI-assisted analysis to synthesize tickets, surveys, and learner feedback
- Building repeatable prompts and workflows for documentation and technical content
- Applying AI tools to speed up editing, formatting, and content repurposing

---

## Why it matters

AI adoption depends on useful examples, judgment, and workflow fit. The goal is not simply to introduce tools; it is to help people understand where AI is useful, where human review matters, and how to build better work habits around it.
