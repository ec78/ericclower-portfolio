# API and Developer Education

I create developer-facing education that helps technical audiences understand how a product works, how to access it, and how to apply it to real workflows. My approach combines demos, examples, documentation, and practical explanations that connect technical details to user goals.

---

## Representative work

At IMPLAN, I expanded API learning resources and became a primary internal lead for API demos related to developer access. This work helps technical users, internal teams, and customer-facing stakeholders understand access patterns, product workflows, and practical use cases.

At Aptech Systems, my work on GAUSS included API design, code examples, documentation, tutorials, and educational resources for advanced statistical and data analysis tools. I helped make complex analytical capabilities easier to adopt by pairing product functionality with clear examples and user guidance.

---

## What this work included

- Creating demos that explain API access and practical product workflows
- Translating technical capabilities into examples for customers and internal teams
- Developing tutorials and documentation that clarify usage patterns and common implementation questions
- Supporting sales, customer success, and product teams with clear technical explanations
- Designing examples that help users move from concept to working implementation
- Connecting developer questions and support patterns back into education priorities

---

## Why it matters

Developer education works best when it reduces uncertainty: what the product can do, how to connect to it, how to structure a workflow, and how to avoid common mistakes. Good examples and demos make the product feel usable sooner.
