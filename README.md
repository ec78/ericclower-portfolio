# Eric Clower — Portfolio

Source for my portfolio site, built with Jekyll and published via GitHub Pages.

**Live site:** https://ec78.github.io/ericclower-portfolio/

The site covers selected work in product adoption, technical enablement, AI workflows, and analytics for complex software products, across roles at IMPLAN and Aptech Systems (GAUSS).

## Structure

- `index.md` — homepage
- `projects/` — case studies and project pages (`projects/projects_landing.md` is the project index)
- `assets/images/` — images used on the site
- `_config.yml` — Jekyll site configuration

The following folders are kept for history and are excluded from the published site in `_config.yml`:

- `archived/` — earlier versions of the homepage and project pages
- `portfolio_update_pack/`, `portfolio_update_integrated_pack/` — drafts from earlier portfolio revisions

Retired project URLs redirect to their current pages via `jekyll-redirect-from`.
