# GAUSS `tspdlib` Library

## Overview

[`tspdlib`](https://docs.aptech.com/gauss/tspdlib/docs/tspdlib-landing.html) is an open-source library for advanced time series modeling in GAUSS. I led this project in collaboration with an expert user, providing strategic support, technical oversight, documentation, and public-facing education resources.

This project shows how I work across product support, open-source enablement, documentation, community collaboration, and promotion.

---

## My Contributions

- Guided the library structure and public resource strategy.
- Authored documentation and use-case examples.
- Supported collaboration with an expert GAUSS user and external contributor.
- Promoted the library through blog content and targeted outreach.
- Helped position the library as a reusable open-source resource for the GAUSS community.
- Supported adoption by connecting documentation, examples, and user education.

---

## Outcomes

The library became one of Aptech's most widely used user-contributed resources and a centerpiece of the contributing user's annual international applied GAUSS workshop.
