# Portfolio Update Pack - Integrated Version

This pack updates the portfolio around a stable long-term positioning:

**Product education, developer enablement, and AI learning strategy for complex technical products.**

## How to use

1. Review the files locally before replacing anything in the live repo.
2. Copy `index.md` to the repository root.
3. Copy all files in the `projects/` folder into the repository's existing `projects/` folder.
4. Existing project pages not included in this pack can remain in the repo. The updated project landing page still links to several current pages.
5. Commit and push to GitHub Pages after reviewing the changes.

## Notes

The new pages intentionally avoid tailoring the portfolio to one employer. They emphasize reusable career alignment across developer education, product education, AI enablement, customer education leadership, technical content strategy, product launch support, and education analytics.

Several pages include placeholders that can become stronger when metrics are available, such as number of tickets analyzed, survey volume, LMS course count, API demo frequency, dashboard KPIs, and support-ticket reduction.
